# Changelog

## 2.0.0 — 2026-09-06

本地交付版本；基于 QiuYeDx/qiuye-skills 的 11ce270，尚未推送或创建远程 release。

### 流程重写

分离规模、风险、不确定性；S 不强制文档，M 只保留小三件套与批次元数据，L 改为滚动规划。
新增受控 spike；允许同一会话连续完成已批准任务；保留审批边界但减少对内部可逆决策的打断。
区分 bugfix/internal-change/behavior-change/spec-correction，禁止通过修改验收条件迎合错误实现。
将 common 改为可选，契约引用遵循真实归属；并行增加协调者、实际写集、共享单写者、依赖基线与集成检查。
按真实状态和接口策略制定验证，不再无差别强制五态、登录鉴权、固定时长或每次跑全量测试。
明确真实数据保护、未提交改动保护、发布/外发/迁移等独立授权。

### 文档与状态

任务元数据和详情合成同一任务块；tasks.md 是唯一任务状态来源。overall 由脚本生成。
spec.json 只保存批次、批准/验收、模块登记、阻断决策和并行分工，不存第二套任务状态。
添加稳定 AC/V 编号，record 建立 AC→检查→证据；增加待验证状态。
批准/任务证据/批次验收各有摘要，发现范围、计划或验收之后任务集合的变化；摘要不冒充签名或源码验证。
模板按需创建，不生成无用记录/验收空表；增加当前 M/L 示例和 S/修复/探索/受限环境说明。

### 工具修复

拒绝重复 BR/R/T/AC/V、重复 JSON 键与元数据；检查依赖缺失、自依赖和环。
废弃任务不提供有效覆盖；按当前批次与 AC 检查覆盖，未来 deferred 不强迫细分任务。
完成记录必须为非空普通文件，任务/日期/版本/环境/指纹一致，required 项和 AC 有逐条证据。
完成/已开始任务不得依赖尚未完成任务，依赖声明需记录当前基线核验；并行快照检查冲突与共享写者。
脚手架校验 feature/module/code、短码冲突和路径，拒绝覆盖与静默 M→L；提供 dry-run。
总览默认 stdout，仅覆盖带生成标记的文件；检查器可检测过期/被手工篡改的总览。
Markdown 解析支持转义管道、忽略 fenced 示例和 HTML 注释，拒绝损坏表格/未闭合围栏；合法 todo 状态枚举不再被当作占位符。

### 兼容性变化

v2 checker 需要 spec.json 和 v2 任务块/AC/record 格式；不再接受 v1 的旧任务台账表，也不保留 --no-vague 参数。
不再自动创建 module-common，不再在已有目录追加模块。新增模块/迁移需按明确步骤维护来源和批准。
Skill 不强制迁移已有业务文档；旧文档继续沿用时采用人工检查，不能声称运行 v2 checker 已通过。

### 验证与未验证

实际自动化测试、示例执行和结构门禁结果见 VALIDATION.md 与 validation/ 日志。
没有运行真实模型 A/B、多 Agent 并行、用户业务项目、浏览器宿主集成或各操作系统原生测试；evals/ 场景用于后续实证，不是测得成绩。
