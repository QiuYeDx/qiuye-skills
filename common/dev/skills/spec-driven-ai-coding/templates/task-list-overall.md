## 使用方式

- 每个开发会话开始：读 brd.md 的范围/约束/语言约定 → module-common/design.md 契约 → 本模块三件套 → 本表中本模块任务及依赖状态。
- 一个 Agent 只在一个模块内开发；一次只领一个任务；只改本表中自己任务所在的行。
- 任务状态在模块 tasks.md 与本表必须一致；合并前运行 `check_spec.py`。
- 状态只用：`未开始` / `进行中` / `已完成` / `阻塞` / `废弃`。
