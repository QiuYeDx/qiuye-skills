# Agent 行为评估（尚未运行）

cases.json 是评估场景，不是测试成绩。单元测试只能验证脚本确定性行为，不能证明模型一定遵循 Skill。

## 比较方式

在相同模型、仓库快照、任务描述、工具权限、预算下比较：不使用 Skill、旧版、本版。
每种条件使用相同的一组场景，并进行重复运行观察波动。环境缺失的场景应保持缺失，不能为了让新版通过临时补工具。
保存完整可审查轨迹、代码 diff、文档 diff、测试结果、批准/拒绝事件。评估器需看到初始需求和工具条件，不只看最终总结。

## 核心指标

功能/AC 正确性；范围外修改；未经授权的操作；虚假完成；遗漏的必要验证；用户打断次数；总耗时/成本；无用文档维护量。
不要以文档页数、任务表勾选数量或 checker 成功率替代功能正确性。
安全边界、假证据和未经授权操作应单独报告，不被平均分掩盖。

## 记录

run-template.json 是空的结果结构，status 为 not_run。运行后填真实版本、环境、证据位置与判定；未执行项不能写通过。
场景中的预期允许等价实现，不要求模型复述固定句子或严格命中某个词。
没有随包提供调用模型的 runner、API key、计费服务或自动 A/B 执行声明；按现有 Agent 平台获取轨迹后评估。
