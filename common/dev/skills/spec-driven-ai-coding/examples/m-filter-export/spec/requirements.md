# 筛选导出：可执行的格式演示

## 目标与范围

演示“筛选后的行导出为 CSV”及其验收/证据关联。现实中这个纯函数小改可用 S；这里采用 M 是为了展示完整文件格式。

## 范围外

不提供 UI、文件下载、上传、服务端权限、数据库、大文件流式处理或跨软件兼容承诺。所有数据为合成示例。

### R-EXPORT-01 只导出满足状态筛选的记录

| 字段 | 值 |
| --- | --- |
| 来源 | 本包可执行演示场景：按 done/todo 筛选 CSV |
| 状态 | active |
| 批次 | I1 |

#### 说明

输入是含 id/name/status 字符串字段的记录 iterable。status 参数仅允许 done 或 todo。
CSV 列顺序为 id,name,status；输出符合筛选条件的行，保持原顺序，不修改输入数据。

#### 验收标准

- AC-EXPORT-01-1: 混合状态数据分别按 done/todo 筛选，结果只含目标状态且顺序与输入一致。
- AC-EXPORT-01-2: 空输入或没有匹配记录时，输出仅包含 CSV 表头。
- AC-EXPORT-01-3: 导出前后原记录内容相同，逗号、双引号和字段内换行可被 CSV reader 还原。

#### 边界与异常

输出字符串使用 CRLF 分行；生成器输入可用；不写文件，不访问网络。

### R-EXPORT-02 拒绝无效数据并处理公式前缀

| 字段 | 值 |
| --- | --- |
| 来源 | 本包演示的输入边界与表格文本处理策略 |
| 状态 | active |
| 批次 | I1 |

#### 说明

所有输入行先校验再筛选；缺少字段、字段不是字符串、未知 status 或非法 id 时抛 ValueError。
id 非空且只允许 ASCII 字母、数字、下划线、连字符。
name 去掉前导空白后以 =/+/-/@ 开头，或原始首字符为制表/回车/换行时，输出字段前加单引号；原数据不改变。

#### 验收标准

- AC-EXPORT-02-1: 非法筛选值和非法输入行（即使本来不会被筛选到）均抛 ValueError。
- AC-EXPORT-02-2: 规定的公式前缀被加单引号，其余文本由 CSV 标准转义，输入不被修改。

#### 边界与异常

这是显式的示例文本规则，不声称覆盖所有电子表格产品的导入行为；生产使用需按目标产品单独验证。
