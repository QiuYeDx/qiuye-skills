# 解析与校验本地记录

### R-INGEST-01 解析与校验本地记录

| 字段 | 值 |
| --- | --- |
| 来源 | BR-01 |
| 状态 | active |
| 批次 | I1 |

#### 说明

在客户端解析 UTF-8 JSON 数组。每条包含字符串 id/name；文件上限 1 MiB，记录上限 1000，id 必须唯一。输入错误抛结构化 ParseError。

#### 验收标准

- AC-INGEST-01-1: 给定包含两条合法记录的 JSON，返回两条等价记录；非法 JSON、缺字段、重复 id、文件超限均返回 ParseError。

#### 边界与异常

不得写服务器；无效数据不返回部分成功结果。
