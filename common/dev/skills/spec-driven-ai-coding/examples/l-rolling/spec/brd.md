# 导入预览路线图（仅规划示例）

## 范围

I1：选择本地 JSON 文件并预览校验后的记录。I2：后续加入异步导出。
本目录没有业务代码或执行证据，所有批准均为 pending。

## 范围外

当前不上传文件，不写生产数据库，不实现账户系统、异步任务或超大数据流式处理。

### BR-01 在页面中预览本地导入记录

| 字段 | 值 |
| --- | --- |
| 状态 | active |
| 批次 | I1 |

#### 说明

操作员选择一个不超过 1 MiB 的 UTF-8 JSON 数组文件，解析合法记录并在页面预览；无效文件显示错误且保留上一成功结果。
大小上限是本示例预设产品约束，不是测得性能指标。

#### 验收要点

选择合法文件后可见内容；非法文件不会替换已有成功内容。

在进入 I2 前细化，目前不承诺具体交互和性能。
